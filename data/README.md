# Dataset

This directory contains the datasets used for the sequential recommendation experiments in this project.

The primary dataset is **MovieLens-1M**, provided by the GroupLens Research Project at the University of Minnesota.

## Directory Structure

```text
data/
├── README.md
├── raw/
│   └── ml-1m/
│       ├── README
│       ├── movies.dat
│       ├── ratings.dat
│       └── users.dat
├── interim/
│   └── ml-1m/
└── processed/
    └── ml-1m/
        ├── bert4rec/
        └── jepa/
```

## Data Organization

### `raw/`

Contains the original MovieLens-1M files after downloading and extracting the official dataset archive.

The original files include:

- `ratings.dat`: User ratings with timestamps.
- `movies.dat`: Movie titles and genre metadata.
- `users.dat`: User demographic information.

Raw files should remain unchanged to preserve the original data and support reproducibility.

### `interim/`

Contains intermediate datasets generated during preprocessing, filtering, sequence construction, and item mapping.

These artifacts are derived from the original dataset and can be regenerated from the raw files using the project's preprocessing pipeline.

### `processed/`

Contains model-ready datasets used by the BERT4Rec and JEPA experiments.

The processed data is organized by model because each architecture requires a different training-example format.

Processed datasets are generated locally and are not required to be committed to version control.

## MovieLens-1M

MovieLens-1M contains approximately one million timestamped movie ratings from 6,040 users.

| Statistic | Value |
|---|---:|
| Ratings | 1,000,209 |
| Users | 6,040 |
| Movies | 3,706 |
| Rating scale | 1–5 stars |

The primary file used in this project is `ratings.dat`, which contains records in the format:

```text
UserID::MovieID::Rating::Timestamp
```

The timestamps are used to order each user's interactions chronologically. Ratings are treated as interactions for the sequential recommendation task.

## Experimental Preprocessing

The current experimental preprocessing uses:

- Minimum movie interaction threshold: 5 ratings
- Maximum user sequence length: 200
- Chronological ordering of interactions
- Contiguous item ID mapping
- Chronological train, validation, and test splitting

The current processed dataset contains:

| Statistic | Value |
|---|---:|
| Users | 6,040 |
| Mapped movies | 3,416 |
| Vocabulary entries, including special tokens | 3,418 |
| Maximum sequence length | 200 |
| Training interactions | 648,759 |

The item vocabulary reserves two special token IDs:

| Token | ID |
|---|---:|
| Padding (`PAD`) | 0 |
| Mask (`MASK`) | 1 |
| Movie items | 2 and above |

The exact number of generated examples can differ between model-specific datasets because BERT4Rec and JEPA construct training examples differently.

### BERT4Rec

BERT4Rec uses masked sequential prediction. Training examples are generated by masking items in a user's interaction sequence and learning to predict the masked items.

### JEPA

JEPA uses context-target pairs. A context sequence is encoded and used to predict a representation of a target item.

The current JEPA data preparation produced approximately 642,719 context-target training pairs in the referenced experiment.

## Dataset Preparation

Obtain MovieLens-1M from the official GroupLens distribution and extract its contents into:

```text
data/raw/ml-1m/
```

The expected raw files are:

```text
data/raw/ml-1m/
├── README
├── movies.dat
├── ratings.dat
└── users.dat
```

If the repository includes the following scripts, use them from the project root:

```bash
python scripts/download_ml1m.py
python scripts/preprocess_ml1m.py
```

Check the actual files in `scripts/` for the supported preparation commands and options.

## Reproducibility

To reproduce the processed datasets:

1. Obtain the original MovieLens-1M dataset.
2. Place the original files in `data/raw/ml-1m/`.
3. Run the preprocessing pipeline available in the repository.
4. Use the corresponding configuration files under `configs/` for training.

Keep preprocessing settings consistent when comparing model results. Changes to filtering, sequence truncation, item mapping, or data splitting can affect the resulting experiments.
